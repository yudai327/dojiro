# ドジロウ！ 仕様書インデックス

このディレクトリには、ドッジボールスコア管理アプリ「ドジロウ！」を任意の言語・アーキテクチャで再実装するために必要な仕様書を収録しています。

---

## ドキュメント一覧

| # | ファイル | 内容 |
|---|----------|------|
| 1 | [01_overview.md](./01_overview.md) | アプリケーション概要・目的・ユーザーロール・用語集 |
| 2 | [02_data_model.md](./02_data_model.md) | エンティティ定義・リレーション・制約・インデックス |
| 3 | [03_api.md](./03_api.md) | 全APIエンドポイント仕様（リクエスト・レスポンス・ステータスコード） |

| 5 | [05_business_rules.md](./05_business_rules.md) | ビジネスルール（スタッツ計算式・バリデーション・ドメインルール） |
| 6 | [06_screens.md](./06_screens.md) | 画面仕様（ページ構成・UIフロー・インタラクション） |

---

## 仕様書の読み方

1. まず `01_overview.md` でアプリ全体の目的と用語を把握する
2. `02_data_model.md` でデータ構造を理解する
3. `04_auth.md` で認証フローを把握する（API実装前に必読）
4. `03_api.md` でバックエンドAPIの全仕様を確認する
5. `05_business_rules.md` でドメイン固有のルールと計算式を確認する
6. `06_screens.md` でフロントエンドの画面設計を確認する

---

## 現行実装の技術スタック（参考）

現行実装は以下の技術で構築されていますが、本仕様書はフレームワーク非依存で記述されています。

| レイヤー | 現行実装 |
|----------|----------|
| フロントエンド | Next.js 14 (App Router) / React 18 / TypeScript / Tailwind CSS |
| バックエンド | Next.js Route Handlers (Node.js) |
| データベース | PostgreSQL (Supabase) / Prisma ORM |
| 認証 | JWT (HS256) + bcrypt |
| テスト | Vitest / MSW |

## スコープ外（現行実装に含まれないが設計上想定している機能）

以下は設計書には記載があるものの現行実装には含まれていない機能です。再実装時に含めるかは要件に応じて判断してください。

- チーム詳細ページ (`/teams/[id]`)
- 選手詳細ページ (`/players/[id]`)
- イベント詳細ページ (`/events/[id]`)
- チーム・選手の累計スタッツ集計 API (`/api/stats/teams`, `/api/stats/players`)
- Set（セット）の作成・更新 API
- PATCH/DELETE エンドポイント（現行は論理削除フラグのみ、PATCH未実装）
- YouTube 動画の埋め込み表示
