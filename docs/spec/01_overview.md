# アプリケーション概要

## 1. アプリ情報

| 項目 | 内容 |
|------|------|
| アプリ名 | ドジロウ！ |
| 英語表記 | Dojiro |
| 目的 | ドッジボールの試合スコアとプレースタッツをブラウザから管理する |

---

## 2. 目的・背景

ドッジボールの試合において、以下を効率的に記録・参照できるWebアプリケーションを提供する。

- 試合のスコア（セットごとのホーム/アウェイ得点）
- 選手ごとのプレーアクション（アタック・キャッチ・カット）の成否
- 大会や練習試合単位での試合グルーピング
- 試合に対応するYouTube動画リンクの管理

---

## 3. 想定ユーザー

| ユーザー種別 | 説明 |
|-------------|------|
| 管理者 (admin) | チームのコーチ・スタッフ・スコアラー。試合中にスコアやプレーアクションを入力する。チーム・選手・大会の登録も行う。 |
| 閲覧者 (viewer) | 保護者・選手本人など。スタッツや試合結果を参照のみ行う。 |
| 未認証ユーザー | ログインページ・ヘルスチェックのみアクセス可能。 |

---

## 4. 機能一覧

### 4.1 認証機能

- メールアドレス＋パスワードによるログイン
- JWTトークンによるセッション管理
- ロールベースアクセス制御（admin / viewer）
- ログアウト（トークン無効化）

### 4.2 チーム管理

- チームの一覧表示
- チームの新規登録（名前・カテゴリ・所属組織）
- チームに属する選手の一覧表示
- 論理削除（物理削除なし）

### 4.3 選手管理

- 選手のチームへの所属
- 選手情報の登録（背番号・氏名・読み仮名・ポジション）
- 論理削除

### 4.4 イベント（大会・練習会）管理

- イベント（大会・練習試合の会）の一覧表示
- イベントの新規登録（名前・種別・開催日程・会場・備考）
- 論理削除

### 4.5 試合管理

- 試合の一覧表示（イベント情報を含む）
- 試合の新規登録（イベント・日時・コート・ホーム/アウェイチーム・YouTube URL・備考）
- 試合詳細の取得（チーム・選手情報を含む）
- 論理削除

### 4.6 スコア入力（プレーアクション記録）

- 試合中に選手のプレーアクション（アタック・キャッチ・カット）を成否付きで記録
- 記録と同時に選手の試合スタッツ（PlayerMatchStats）を自動更新
- 同一試合内で何度でも記録可能

### 4.7 スタッツ閲覧

- 試合ごとの選手別スタッツ一覧
- アタック成功率・キャッチ成功率の算出
- スタッツは入力のたびにリアルタイムに反映

---

## 5. 非機能要件

| 項目 | 要件 |
|------|------|
| スケール | 数チーム〜数十チーム規模。同時編集ユーザーは最大十数人程度 |
| 認証方式 | JWTトークン（有効期限7日） |
| パスワード保護 | bcryptによるハッシュ化（コストファクター10） |
| ソフトデリート | すべてのエンティティはフラグで論理削除。物理削除は行わない |
| データ整合性 | トークン無効化にtokenVersionを使用。ログアウト時にインクリメント |
| セキュリティ | APIはBearerトークン認証。ページアクセスはhttpOnly Cookieで制御 |

## 6. 用語集（ドメイン用語）

| 用語 | 英語キー | 説明 |
|------|----------|------|
| イベント | event | 大会・練習試合の会など、試合をグルーピングする上位概念 |
| 試合 | match | 2チームが対戦する1試合。イベントに属する |
| セット | set | 試合内の1セット。セット番号・ホーム/アウェイ得点を持つ |
| チーム | team | 選手の集合体。ホームまたはアウェイとして試合に参加 |
| 選手 | player | チームに所属する個人。背番号・氏名などを持つ |
| プレーアクション | player_action | 試合中の選手の個別アクション記録（アタック/キャッチ/カット） |
| 試合スタッツ | player_match_stats | 試合×選手の集計値。アクションが記録されるたびに更新 |
| アタック | attack | ボールを投げる攻撃アクション。成功/失敗がある |
| キャッチ | catch | 相手の攻撃ボールを捕球するアクション。成功/失敗がある |
| カット | cut | ボールをカットして味方につなぐアクション。成功のみ記録 |
| アタック率 | attack_rate | アタック成功数 ÷ アタック試行数 |
| キャッチ率 | catch_rate | (キャッチ成功数 + カット数) ÷ キャッチ試行総数 |
| 論理削除 | soft delete | is_deletedフラグをtrueにすることで削除済みとみなす処理 |
| ホームチーム | home team | 試合においてホーム側として登録されたチーム |
| アウェイチーム | away team | 試合においてアウェイ側として登録されたチーム |

---

## 7. ユーザーロール定義

### admin（管理者）

- GETリクエスト：すべてのリソースを参照可能
- POST/PATCH/DELETEリクエスト：すべての書き込み操作が可能

### viewer（閲覧者）

- GETリクエスト：すべてのリソースを参照可能
- POST/PATCH/DELETEリクエスト：**禁止**（403 Forbidden）

### 未認証

- `/api/health` と `POST /api/auth/login` のみアクセス可能
- その他のAPIは401 Unauthorizedを返す
- ページアクセスはログインページにリダイレクト
